# QuillDev Homebrew Tap

Homebrew formulae for [QuillDev](https://github.com/QuillDev) projects.

## NaNotes

A Nako-styled floating Markdown scratchpad backed by local files.

```bash
brew install quilldev/tap/nanotes
```

The formula builds from source (Homebrew pulls in the Rust and Node build
tools). See the [NaNotes repo](https://github.com/QuillDev/nanotes) for details.
