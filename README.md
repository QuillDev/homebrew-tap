# QuillDev Homebrew Tap

Official Homebrew formulae for [QuillDev](https://github.com/QuillDev) projects.

## Nakode

A provider-neutral terminal workspace for coding agents.

```bash
brew install quilldev/tap/nakode
```

See the [Nakode repository](https://github.com/QuillDev/nakode) for supported
providers and usage.

## NaNotes

A Nako-styled floating Markdown scratchpad backed by local files.

```bash
brew install quilldev/tap/nanotes
```

The formula builds from source (Homebrew pulls in the Rust and Node build
tools). See the [NaNotes repo](https://github.com/QuillDev/nanotes) for details.
